# Nobody's Life OS v2

一个无需后台服务器、可安装到 iPhone 主屏幕的生活规划 PWA。

## 功能

- 每周打卡：阅读 4 次、吉他 2 次、电影 2 部、韩剧 2 次、晨练 3 次、网球 3 次（所有目标可更改）。
- 选择日期打卡及补打卡、撤销记录、周统计与本月概览。
- 浮动日程：日期、跨日结束日期、时间、备注、编辑/删除；月历与按周浏览；新建时提示日程冲突。
- 兴趣收藏：书籍、电影、韩剧、吉他曲的状态和感想。
- 深色 / 浅色 / 跟随系统，适配 iPhone 17 的安全区域。
- 离线打开（首次在线访问后缓存应用文件）；JSON 全量备份/恢复、CSV 打卡导出。
- 对午夜结束兼职课程的晨练恢复提示。

## GitHub Pages 发布（一次即可）

1. 在 GitHub 创建公开仓库，例如 `nobody-life-os`。
2. 将此目录**里面的文件**（`index.html`、`app.js` 等）上传到仓库的**根目录**，不是再套一层文件夹。
3. 仓库 Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save。
4. 等 GitHub Pages 显示站点地址，通常为 `https://你的用户名.github.io/nobody-life-os/`。以 GitHub 实际显示为准。
5. iPhone 的 Safari 打开上述网址 → 分享 → 添加到主屏幕。首次访问需要网络，后续已经缓存的应用可以离线运行。

## 数据与更新

- 数据只存在**当前设备的浏览器本地存储**，不会传到 GitHub。
- 清理 Safari 网站数据、卸载或更换手机，都可能导致数据丢失。建议每周或每月在「设置 → 导出 JSON 备份」保存一份。
- 本应用**不提供跨设备实时同步、系统推送通知或自动后台排程**。
- 当前版本继续读取 v1 的 `nobody-life-os-v1` 本地数据；JSON 备份兼容旧版。升级时请在**同一个 GitHub Pages 地址**部署，保留数据源站点不变。
- 以后版本更新，只需在同一个 GitHub 仓库替换更改过的文件；不需要再建仓库。发布完成后重新打开 App 即可获取新版本（若缓存旧版本，可关闭并再次打开）。

## 技术

原生 HTML/CSS/JavaScript；无第三方依赖或跟踪脚本；GitHub Pages 静态托管。文件 `sw.js` 负责缓存应用壳。建议使用 HTTPS 访问。
