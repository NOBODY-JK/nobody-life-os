# Nobody's Life OS V4.0.1

以周目标为规划核心，保留每日安排、月度汇总和长期积累的本地优先 PWA。无需后台、账号、依赖安装或构建。仓库原地址可以保留。

## 本地预览

在这个目录运行 `npm start`，访问 `http://127.0.0.1:4173/`。不要直接双击 HTML：模块与离线功能需要 HTTP/HTTPS。

测试：`npm test`。语法检查：`npm run check`。运行测试需要支持 `node:test` 的 Node.js。

## 功能

- 本周：周目标快照、已完成 / 已安排 / 待安排、七天概览、待安排池、灵感收件箱、复制上周、周初规划与周末复盘。
- 日程：日 / 周 / 月 / 未来 30 天议程，活动筛选和搜索；跨夜与多日计划；每日 / 每周重复（截止日期内实体化，最多 366 次）；单次或整个系列编辑、改期、跳过、恢复、取消、复制。
- 洞察：日 / 周 / 月 / 近 90 天 / 年度事实汇总，八周时长图、活动时间分布、类别汇总、前一等长时段对比、完成记录和关联作品。
- 我的：活动名称、分类、图标、颜色、默认时长、次数 / 分钟 / 数量 / 无目标、统计口径、启用 / 暂停 / 归档；详情页；作品状态、评分、感想及完成关联。
- 全局：快捷新增、搜索、完成 / 补记 / 编辑 / 撤销、首页模块顺序和隐藏、主题、睡眠与活动时段、JSON 备份恢复、CSV 导出、多标签页冲突保护、离线使用。

## 首次升级，先保护现有数据

1. 在手机原 App 的「设置 → 导出 JSON 备份」，将文件存到 iCloud Drive 或电脑。**手机数据在浏览器里，不在 GitHub 仓库中；本项目没有读取或代备份你的真实生活记录。**
2. 备份现有仓库，记录当前提交。此包已保存读取到的 v2 原始源文件于 `backups/upstream-v2/`，原提交为 `e4da601c188638669f62cc8dd1b9c4b037d47772`。仓库只发现 `main`，没有独立 v3 分支。
3. 在同一个 GitHub Pages 地址更新，保留原域名和路径；不要清理 Safari 网站数据。V4 首次启动会先原样保存 `nobody-life-os-v1` 到 `nobody-life-os-backup-before-v4`，再迁移到 `nobody-life-os-v4`。原键不会删除或改写。备份或迁移失败时停止写入，显示救援下载入口。
4. 核对旧打卡条数、日程和作品。换设备或在不同域名预览时，通过「我的 → 导入 / 恢复」导入 JSON；导入先预检，确认后保存替换前快照，可从「本机历史快照」下载还原。
5. 如果有未识别的旧格式，导入会拒绝并保留当前数据；提供原始文件后才能安全补充适配。已验证兼容仓库 v2 使用的 v1 存储 / JSON 格式，以及 V4 备份，不宣称支持未见过的 v3 格式。

## 一次性更新 GitHub Pages

使用 `nobody-life-os-v4.0.0-pages.zip`：解压后将**内部文件一次性提交到原仓库根目录**，不再套一层文件夹。一次提交包含 `index.html`、`app.js`、`core.js`、`style.css`、`sw.js`、`manifest.webmanifest`、`icon.svg`、三个 PNG 和 `.nojekyll`，避免混用新旧版本。

如果现有 Pages 使用 `main / (root)`，保持该设置即可。若设置不同，先核实现有发布方式再部署；本包不更改仓库设置，也没有替你部署。只有 GitHub 的实际部署成功且核对站点后，才算发布。

旧 v2 的缓存优先策略会阻挡新界面。V4 离线组件安装完成后会识别 v1/v2/v3 缓存、接管并刷新旧窗口，只删除本应用缓存，不删除本地数据。常规 V4 更新通过「检查应用更新」主动激活。升级后若仍显示旧界面，联网关闭并重开 App，再刷新；不要通过清空网站数据解决。

## 数据规则

- 所有关系使用稳定活动 ID；名称变化同步到历史展示。归档保留记录。
- 计划不等于成果；同一日程只能有一条完成记录。作品状态也不会自动生成成果。
- 主要周目标按次数、实际分钟或实际数量计算；分钟与数量可同时作为辅助记录。
- 历史周保留目标快照。修改默认目标可以从本周或下周生效，某周目标可单独调整。
- 完成按实际完成日期归属周；跨夜计划在涉及的日期展示。时间使用设备本地时区，出行换时区不会转换已保存的本地时间。
- 旧版打卡没有时长和日程关联 ID：保留次数，时长标为未知；不会推测某次旧打卡属于哪个日程。旧版也没有目标变更历史，迁移快照使用备份里的目标，无法重建此前变化。
- 导入为全量恢复，不是合并。导入前自动快照，建议同时下载独立备份；本机快照也可能随浏览器数据清理而丢失。
- 没有云同步、系统推送或后台自动排程。

## iPhone 与离线

适配窄屏、底部导航、安全区域和动态视口；提供 Apple 主屏幕 PNG。Safari 分享 → 添加到主屏幕。首次完整联网加载并完成缓存后，可断网打开、记录和编辑。

已做 393×852、402×874 响应式浏览器检查；**未在实体 iPhone 17 / Safari 主屏幕模式上完成验收**。发布前应在你的手机上核对迁移数量、键盘、日期控件、主屏幕和离线体验。

开发与验证详情见 `VALIDATION.md`。
